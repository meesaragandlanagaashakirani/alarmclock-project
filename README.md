## How It Works

1. The user enters the desired alarm time in HH:MM:SS format.
2. The program continuously checks the current system time.
3. The current time is compared with the alarm time every second.
4. When both times match, the alarm sound is played.
5. The alarm continues until the user stops it or the sound file finishes playing.
